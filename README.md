# 🖤 VÉLORA Parfums — Haute Parfumerie E-Commerce Website

> **Final Project Demo — DTI 224 Web Development**  
> An ultra-luxury French perfumery boutique e-commerce web application featuring interactive olfactory recommendations, responsive shopping bag drawer, and digital certificate receipt generation.

---

## ✦ Overview

**VÉLORA Parfums** is a luxury boutique concept website developed using vanilla **HTML5**, **CSS3**, and **JavaScript (DOM/BOM)**. Built around an editorial Black & Gold aesthetic, the application provides an authentic Parisian high-perfumery online shopping experience.

## ✨ Key Features

- **Editorial Luxury UI/UX**: Black & Gold colorway, glassmorphism modals, smooth CSS transitions, and typography using Cormorant Garamond & Montserrat.
- **Interactive AI Scent Sommelier Quiz**: Recommends the ideal fragrance edition based on user mood and scent preference.
- **Product Quick View Modal**: Dynamic flacon size selection (50ml / 100ml) with real-time price updates and pyramid olfactory notes breakdown.
- **Full Shopping Bag Drawer**: Slide-in cart with persistent `localStorage` storage, quantity controls (+/-), and subtotal calculation.
- **2-Column Boutique Checkout**:
  - Client & delivery destination form
  - White-glove vs. VIP Same-Day Chauffeur delivery options
  - Complimentary handwritten calligraphy gift inscription option
  - 3 Payment channels: PromptPay QR (with bank details & slip preview), Credit/Debit card with formatting, and Cash on Delivery
  - Promotional voucher code validation (`VELORA10` for 10% off, `VIP300` for ฿300 off)
- **Deluxe Official Receipt & Certificate of Authenticity**:
  - Itemized manifest table with bottle mockups
  - Order reference tracking ID and delivery estimate
  - Paris Wax Seal watermark guarantee
  - One-click **Print Receipt** with optimized `@media print` layout
  - Plaintext receipt file export (`.txt` download)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox). No build tools, external node servers, or dependencies required!

```bash
# Clone the repository
git clone https://github.com/RexX0Dora1005/VELORA-PERFUME.git

# Navigate to directory
cd VELORA-PERFUME

# Open in browser
start index.html
```
